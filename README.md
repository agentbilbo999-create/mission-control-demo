# Mission Control Demo

Public-safe staging copy of Mission Control.

## Safety / Isolation
- Static HTML only
- Runs entirely in the browser
- Uses demo sample cards only
- Stores state only in the viewer's browser localStorage under mission-control-demo-v1
- No connection to local OpenClaw runtime, private files, MEMORY.md, credentials, or real operational data

## Environment
- GitHub Pages (static hosting)
- Repository intended for public demo/review use
